# Лабораторна робота №4. Обробка рядків та регулярні вирази (Варіант 5)

Python 3.9+, лише стандартна бібліотека.

| Файл | Призначення |
|------|-------------|
| `text_analyzer.py` | функції для рядків, регулярні вирази, аналіз тексту, консольне меню |
| `test_text_analyzer.py` | unit-тести для `text_analyzer.py` |
| `variant5.py` | **варіант 5**: числові значення з одиницями вимірювання + назви екокуполів (`EC-Dome-N`) |
| `test_variant5.py` | unit-тести для `variant5.py` |
| `neoterra.txt` | спільний текст «NeoTerra 3000» |

## Запуск

```bash
python text_analyzer.py                                  # інтерактивне меню
python variant5.py                                       # витяг даних з neoterra.txt
python -m unittest test_text_analyzer test_variant5 -v   # тести
```
